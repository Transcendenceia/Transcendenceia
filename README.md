# TranscendenceIA

**Ideas que se piensan. Proyectos que se construyen.**

Soy Marlon, creador de TranscendenceIA. Conecto la parte física y digital de una idea: sistemas Linux, software, automatización, agentes IA, electrónica y diseño/prototipado 3D.

Aquí comparto código y herramientas. En la web y el canal muestro procesos, demostraciones y reflexiones sobre la tecnología y lo que hacemos con ella.

## Crear · Explicar · Reflexionar

- **Crear:** desarrollar proyectos para necesidades concretas.
- **Explicar:** mostrar cómo funcionan, qué se ha probado y cuáles son sus límites.
- **Reflexionar:** pensar en el impacto de nuestras herramientas y decisiones.

## Proyectos y herramientas

| Proyecto | Qué encontrarás |
| --- | --- |
| [La Aguja](https://github.com/Transcendenceia/La-Aguja) | Linux live desde USB, herramientas de IA e imager para preparar un entorno independiente del sistema instalado. Proyecto experimental. [Web y documentación](https://aguja.transcendenceia.net/es). |
| [opnsense-admin-skill](https://github.com/Transcendenceia/opnsense-admin-skill) | Herramientas e instrucciones para administración de OPNsense con agentes IA mediante API y SSH. |
| [ntopng-admin-skill](https://github.com/Transcendenceia/ntopng-admin-skill) | Herramientas e instrucciones para analizar tráfico, hosts y alertas de ntopng con agentes IA. |

La Aguja es uno de los proyectos de TranscendenceIA. El trabajo también abarca automatización, sistemas, IoT y soluciones físicas. Cada repositorio documenta su propio alcance y requisitos.
